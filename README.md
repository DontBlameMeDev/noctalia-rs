## Installation

### System-Wide

To install the tool system-wide, you can use the following command:

```bash
nix profile add git+https://codeberg.org/DontBlameMe/noctalia_rs
```

### One-off Execution

To run the tool only once, without installing it system-wide, you can use the
following command:

```bash
nix run git+https://codeberg.org/DontBlameMe/noctalia_rs
```
